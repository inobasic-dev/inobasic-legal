Rodri TikTok 自動投稿 プライバシーポリシー

最終更新日: 2026年5月28日
施行日: 2026年5月28日

本サービス（以下「本アプリ」といいます）は、福岡市中央区の日本酒バー「日本酒の学校 福岡赤坂本店」店長ロドリの紹介動画を、当社のサーバーから TikTok（@rodri_loves_sake アカウント）へ自動投稿するための内部運用ツールです。本アプリは一般エンドユーザー向けの公開アプリではなく、利用者は当社運営者および提携店舗の関係者に限定されます。本アプリは Google Drive にアップロードされた動画ファイルとそのファイル名、TikTok アカウントへの投稿に必要なアクセストークン、および AI による紹介文生成結果のみを取り扱います。

本アプリは、INOBASIC, K.K.（以下「当社」といいます）が提供します。本アプリの運用にあたり、お客様の個人情報・利用データの取り扱いについて以下のとおり定めます。

1. 収集する情報と利用目的

本アプリは、エンドユーザーから直接情報を収集するインターフェースを持ちません。本アプリが当社サーバー上に保管する情報は以下のみです。

  • 動画ファイル（一時保管）: 提携店舗の店長が Google Drive にアップロードした動画ファイル。TikTok への投稿に必要な間のみ当社サーバーに一時ダウンロードし、投稿完了後に即時削除します
  • 動画ファイル名: ファイル名から紹介対象の銘柄名を抽出し、AI 生成キャプションのプロンプトとして利用します
  • TikTok アクセストークン / リフレッシュトークン: TikTok Content Posting API への投稿に必要な認証情報。Laravel フレームワークの暗号化機能（アプリケーションレベル暗号化）を用いてデータベースに保管します
  • 投稿メタデータ: TikTok 投稿後に発行される投稿 ID、投稿時刻、投稿ステータス（成功・失敗・リトライ等）
  • 運用ログ: バッチ実行ログ、エラーメッセージ、リトライ回数等。トラブルシュート目的で 30 日間保管後に自動削除します

上記情報は、TikTok への自動投稿という単一の目的のみに利用し、それ以外の用途には使用しません。

2. 通信について

本アプリは、サーバーサイドのバッチ処理として動作し、以下の外部サービスと通信します。

  • TikTok Content Posting API: 動画ファイルおよびキャプションを TikTok プラットフォーム（運営: TikTok Pte. Ltd. / ByteDance Ltd.）に送信し、投稿します
  • Google Drive API: 提携店舗がアップロードした動画ファイルを取得します
  • Google Gemini API: 紹介する銘柄名から TikTok キャプションの冒頭文を AI で自動生成します。生成のために送信するのは動画ファイル名から抽出した銘柄名のみで、動画ファイル本体や個人情報は送信しません

これらの通信は、当社サーバーから各 API サービスに対して行われ、エンドユーザーの端末との直接通信は発生しません。

3. 端末の機能の利用

本アプリはサーバーサイドで動作するバッチ処理アプリケーションであり、エンドユーザーの端末機能（カメラ、マイク、位置情報、連絡先、写真、ヘルスケアデータ等）は一切利用しません。エンドユーザー向けのモバイルアプリ・Web アプリは存在しません。

4. 第三者提供・サブプロセッサ

本アプリの運用にあたり、以下の第三者サービス（サブプロセッサ）を利用します。これらへのデータ送信は、本アプリの目的達成のために必要最小限の範囲で行います。

  • TikTok Pte. Ltd. / ByteDance Ltd.: 動画投稿の宛先。送信するデータは動画ファイル、キャプション、投稿オプション、認証トークン
  • Google LLC: 動画ファイルの保管・取得元（Google Drive）および AI キャプション生成エンジン（Gemini API）。Google Drive には提携店舗が動画ファイル本体およびファイル名を保管し、本アプリは Google Drive API を介して当該ファイルを取得します。Gemini API には動画ファイル名から抽出した銘柄名のテキストのみを送信し、動画ファイル本体や個人情報は送信しません

各サブプロセッサのプライバシーポリシーは、各社の公式サイトをご確認ください。当社は、上記以外の第三者へお客様の情報を提供することはありません。

5. 広告・解析ツール

本アプリには、本ポリシーの最終更新日時点で、広告および第三者の解析ツールは導入されていません。本アプリは TikTok 投稿のためのサーバーサイドツールであり、エンドユーザーの行動追跡・トラッキングを行うことはありません。

6. データの保管期間

  • 動画ファイル: TikTok 投稿完了後、当社サーバー上から即時削除します
  • TikTok アクセストークン / リフレッシュトークン: 提携店舗による再 authorize（再認可）まで暗号化された状態でデータベースに保管します。提携店舗が連携を解除した場合、すみやかに削除します
  • 投稿メタデータ: 投稿の重複防止および運用記録のため、データベースに継続的に保管します
  • 運用ログ: 30 日間保管後、自動的に削除されます

7. データ削除請求

提携店舗の関係者は、当社に対して保管中のデータの削除を請求することができます。削除請求があった場合、当社は請求受領後 7 日以内に対応し、削除完了をご連絡します。削除請求は本ポリシー末尾のお問い合わせ先までご連絡ください。

TikTok 上に投稿された動画自体の削除については、TikTok アカウント保有者（提携店舗）が直接 TikTok アプリ・サービス上で行ってください。当社は TikTok 投稿済みコンテンツの削除権限を行使する手段を有しますが、コンテンツ削除の最終的な操作・確認は TikTok アカウント保有者の責任で行うものとします。

8. お子様の利用について

本アプリは内部運用ツールであり、エンドユーザー向けの提供は行いません。13 歳未満のお子様から意図的に個人情報を収集することはありません。

9. GDPR・CCPA への対応

当社は、欧州一般データ保護規則（GDPR）、カリフォルニア州消費者プライバシー法（CCPA）その他の適用法令の範囲で、お客様の権利（アクセス、訂正、削除、データポータビリティ等）に対応します。本アプリは特定の提携店舗関係者のみが利用するため、対象データは限定的ですが、関係者からの権利行使請求にはすみやかに対応します。

10. セキュリティ

当社は、本アプリが取り扱うデータ（特に TikTok アクセストークン）を保護するため、以下のセキュリティ対策を講じています。

  • アクセストークン・リフレッシュトークンはアプリケーションレベルで暗号化してデータベースに保管
  • サーバー OS・ミドルウェア・依存ライブラリの定期的なセキュリティアップデート
  • 運用ログにおいて、トークン・認証情報・URL 内のクエリ文字列を出力しないマスキング処理
  • 本アプリのバックエンドコードへのアクセス権限を当社の運営担当者に限定

11. 投稿コンテンツに関する責任

TikTok に投稿される動画コンテンツ、キャプション、ハッシュタグの内容、適法性、著作権、TikTok コミュニティガイドラインへの適合性は、提携店舗（コンテンツの提供元）の責任に帰属します。当社は、本アプリを通じて投稿された個別のコンテンツに関する一切の責任を負いません。

12. プライバシーポリシーの変更

本ポリシーの内容は、必要に応じて変更されることがあります。重要な変更がある場合は、本ページにて告知し、変更内容を明示します。重大な変更（取り扱いデータの種類の追加、第三者提供範囲の拡大等）の場合は、提携店舗への事前通知および合意を取得します。
